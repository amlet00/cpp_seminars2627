## Реализация паттерна стратегии и декоратора, используя functional.

### Суть:

Посчитать урон для Entity, используя одну из стратегий атаки (физический, магический или чистый урон). Возможны модификации атаки в виде двойного урона, критического урона.

### Стратегии:

- PhysicalDamageStrategy
- MagicDamageStrategy
- TrueDamageStrategy

### Декораторы:

- DoubleDamage
- CriticalDamage
